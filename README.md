# Ghost Driver Suite

Suite for Ghost Driver focused on the drive loop: automated driving, round completion and farm pacing.

## Scope

The suite bundles 4 modules: automated driving; automated match completion; hands-free progression loop; Infinite Money.

Each module is an independent toggle; nothing runs before you enable it.

## Loadstring

```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/StapleArmorerAxe15/combine-presets/main/ghost-driver-auto-drive-auto-win-auto-fa-ofw.lua'))()
```

## How to run

1. Join the game.
2. Attach your runtime.
3. Execute the line above; the menu builds in-game.
